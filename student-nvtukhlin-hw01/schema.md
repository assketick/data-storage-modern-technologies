# Схема данных

Источник: Wikimedia Pageviews (en.wikipedia), два часа за 2015-05-01 (01:00 и 02:00 UTC).
Единица наблюдения: число просмотров одной страницы en.wikipedia.org за один час.

## Итоговая схема (staging CSV, Parquet, Iceberg-таблица `lakehouse.nvtukhlin.wikipageviews`)

| Поле | Тип | Nullable | Смысл |
|---|---|---|---|
| `domain_code` | STRING | нет (после DQ) | Код проекта Wikimedia; после фильтрации в `02_prepare_csv.py` всегда `en` (обычная English Wikipedia, без мобильной `en.m` и прочих проектов). |
| `page_title` | STRING | нет (после DQ) | Заголовок страницы MediaWiki, с подчёркиваниями вместо пробелов, как в оригинальном дампе. Уникальность внутри одного часа не гарантируется источником явно, но на практике MediaWiki уже агрегирует по (title, час) на своей стороне. |
| `count_views` | INT | нет (после DQ) | Число просмотров страницы за час — числовая мера. Отрицательные значения считаются невозможными и отбрасываются. |
| `total_response_size` | INT | да | Устаревшее поле Wikimedia, во всех наблюдаемых строках равно `0` (не заполняется дампами этой эпохи) — это ожидаемый и допустимый факт, не ошибка данных. |
| `event_date` | DATE | нет | Дата часа наблюдения, взята из имени файла-источника (`pageviews-YYYYMMDD-HHmmss.gz`), не хранится в самих строках дампа. |
| `event_hour` | INT | нет | Час наблюдения (1 или 2), взят из имени файла. Используется как ключ партиционирования и как граница двух непересекающихся порций Iceberg. |
| `namespace` | STRING | нет | Производное поле — пространство имён MediaWiki, извлечённое из префикса `page_title` до `:` (`Special`, `Talk`, `User`, `Category`, `File`, `Template`, …) при условии, что префикс входит в список настоящих namespace en.wikipedia; иначе `(article)` (обычная статья, включая заголовки с двоеточием внутри самого названия, например `ISO_3166-2`). Категориальное поле для анализа. |

## Что было в исходном (не-CSV) источнике и что добавлено

Исходный `.gz`-дамп — текст с полями через пробел без заголовка и без колонки времени:
`domain_code page_title count_views total_response_size`. Час и дата в строках отсутствуют —
они взяты из имени файла и добавлены как `event_date`/`event_hour` на шаге подготовки CSV
(`02_prepare_csv.py`), это не искусственные колонки, а перенос метаданных имени файла в данные.
Поле `namespace` добавлено в `pipeline.py` как явно объяснимое производное значение, а не
случайная категория.
